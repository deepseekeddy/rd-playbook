# 设计交付检查

核对 PRD 版本和 `REQ-ID`，再检查关键流程、页面状态、组件、变量、响应式、可访问性、文案、资源和原型。

必须覆盖：Loading/Empty/Error/Success/Disabled；权限差异；边界数据；移动/桌面断点；键盘与焦点；组件复用与变体；切图/图标许可；设计版本冻结链接。

输出：设计范围、页面/FR 映射、状态矩阵、组件映射、交互说明、响应式/可访问性、资源清单、缺口、验收截图清单、结论。

Figma 是视觉事实源；PRD 只记录链接、版本和验收摘要。完成定义：开发无需猜测关键状态，QA 能从交付物生成视觉与交互用例。
