# 运营与观测

建立三层指标：业务结果、用户体验、系统健康。每项包含口径、基线、目标/阈值、数据源、Owner 和观察周期。

发布后检查错误率、延迟、饱和度、关键业务漏斗、客服/用户反馈和成本。异常时先止损，按预案决定暂停灰度、回滚或降级。

复盘使用无责结构：时间线、影响、发现方式、根因、促成因素、处置、有效/无效动作、改进项。改进项必须有 Owner、期限和验证方式，并回流需求池或 Skill。

输出：观测结论、指标变化、异常、处置建议、复盘摘要、改进 backlog、是否关闭观察窗。
