# 测试与验收

使用 [assets/test-matrix-template.md](assets/test-matrix-template.md) 建立追踪矩阵。

建立 `FR-ID → 风险 → 测试层级 → 用例 → 自动化 → 结果` 追踪矩阵。

覆盖：功能、权限、安全、异常、边界、并发、兼容、性能、可访问性、可观测性、迁移与回滚。优先把高频、高影响、易回归路径自动化。

每个用例包含前置、数据、步骤、预期和证据。缺陷包含严重度、环境、版本、复现率、日志/截图和关联需求。

输出：范围、风险、环境/数据、测试矩阵、回归集、自动化建议、结果、缺陷、残余风险、Go/No-Go 建议。

没有实际执行记录时只能输出计划或待验证结论，不能宣称通过。
