# PRD 评审

检查价值与指标、范围、用户旅程、业务规则、权限、状态与异常、非功能、埋点、验收、依赖和风险。

发现项按严重度输出：`Blocker` 无法进入下一阶段；`Major` 高概率返工/漏测；`Minor` 可优化。每条包含位置、问题、影响、建议和 Owner。

最后给出结论：`Approved`、`Approved with actions` 或 `Rejected`；附必须完成项、可延后项和需要重新评审的触发条件。

不要仅做文字润色。重点验证需求是否一致、可实现、可测试、可观测。没有批准证据时不得标记 Approved。
